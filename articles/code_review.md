コードは債務(liability)必要な債務かもしれないが、それ自体では,どこかの誰かにとっての将来の単なる保守タスクである

コードを開発する前に,開発に足る正当な理由があることを確認する必要がある
重複したコードは労力の無駄であるだけでなく,やがてはそのコーどに起因するコストが全く存在しない場合より実際には高くなることがある
